# Description
Builds the strongest possible case for the opposing side of a position, the version its smartest defenders would make.

# Usage
- /steelman the case against my proposal to switch to a four-day week
- /steelman the view I disagree with: [paste]

# Purpose
Give the user the best version of an argument they disagree with so they can test their own view against it.

# Grounding
Look for the real arguments and evidence the other side uses: user content first, then the sources in the search order. If none is found, build the case from reasoning and label it as such.

# Workflow
1. Identify the position being opposed and the best version of the opposing view.
2. Present it as its thoughtful supporters would, with their strongest evidence and reasoning.
3. Name the values or priorities that make the view reasonable.
4. Note where it is strongest against the user's position.
5. Close with a short, fair rebuttal so both sides are visible.

# Output Format
**The case:** 3-4 strongest arguments, in order

**Why smart people hold it:** the underlying values or evidence

**Where it bites:** the weakest point in the user's position

**Fair rebuttal:** a few sentences

# Rules
- No strawmen and no hedging the argument into mush.
- Present it as the other side's case, not as the agent's personal view.
- Do not invent evidence or quotes.
