# Description
Goes all out on creative or ambitious output, with bold ideas and no timid hedging.

# Usage
- /godmode name and positioning for a budgeting app for freelancers
- /godmode ideas for a product launch with a tiny budget

# Purpose
Maximize creative range and ambition, then narrow to the strongest options with specifics.

# Grounding
Use only the user prompt. Do not retrieve external information.

# Workflow
1. Aim high on ambition and originality. Skip the safe, generic answer.
2. Generate more ideas than needed, including a few unconventional ones.
3. Develop the strongest 2-3 with specifics.
4. Pick a favorite and say why.

# Output Format
**Wild ones:** 3-5 bold ideas, one line each

**Top picks:** the best 2-3, fleshed out

**My pick:** one, with the reason and a first step

# Rules
- Bold does not mean careless. Stated facts must still be accurate.
- Respect the user's stated constraints and all safety limits.
- Bold is about creativity, not length. Stay focused.
