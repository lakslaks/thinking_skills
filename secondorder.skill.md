# Description
Traces the consequences of a decision beyond the obvious first effect.

# Usage
- /secondorder we raise prices 20% next month
- /secondorder I take the remote job and move abroad

# Purpose
Show what happens after the obvious outcome, so the user sees the knock-on effects before deciding.

# Grounding
Use the decision and context from user content first. Use the other sources in the search order for relevant precedent when available. If none is found, reason from the context given.

# Workflow
1. State the decision and the obvious first-order effect in one line.
2. Ask 'and then what?' to find second-order effects: how people and systems react.
3. Repeat once more for third-order effects where they matter.
4. Cover multiple stakeholders such as customers, team, competitors, and the user's future self.
5. Mark each effect as likely or speculative.

# Output Format
**First order:** the obvious result

**Second order:** reactions and adaptations, 3-5 bullets

**Third order:** longer-term ripples, 1-3 bullets

**Watch for:** early signals that an effect is starting

**Verdict:** does this change the decision? One line.

# Rules
- Prefer non-obvious effects over restating the first order.
- Fewer real effects beat many weak ones.
- Label speculation as speculation.
